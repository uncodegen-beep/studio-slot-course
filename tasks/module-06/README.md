# Урок 80. Расписание зала

Добавьте чтение ежедневного расписания в карточку студии. Чтение доступно гостю. Изменение студии
по-прежнему требует роли владельца и проверки принадлежности студии.

1. Опишите GET `api/studios/:studioId/rooms/:roomId/slots`. Для существующего зала ответ содержит
   массив целых часов начала. Для закрытой студии верните пустой массив, для неизвестного зала
   — 404.
2. Используйте часы и шаг из BookingConfig. Проверьте ответ через Zod до передачи компоненту.
3. Покажите расписание выбранного зала, состояния загрузки и ошибки. При смене зала старый ответ не
   должен менять новое расписание.
4. Проверьте матрицу доступа: гость читает расписание, клиент получает 403 при попытке изменить
   студию, владелец редактирует только свои студии. Проверьте также неверный формат ответа.

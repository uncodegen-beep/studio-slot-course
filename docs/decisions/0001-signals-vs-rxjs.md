# 0001. Сигналы или RxJS

Статус: принято, урок 67.

## Правило

- **Сигнал** — состояние: «что есть сейчас». Читается синхронно, сам обновляет шаблон.
- **RxJS** — события во времени: «что и когда произошло». Пауза, отмена, повтор, очередь,
  объединение источников.
- **Мост** — `toSignal` и `toObservable`: время и отмена внутри потока, а на входе и выходе —
  сигналы.
- **Загрузка данных для экрана** — `resource`, `rxResource` или `httpResource`: загрузка, значение и
  ошибка уже в сигналах.

## Решения в StudioSlot

| Где                                              | Выбор                                                             | Почему                                            |
| ------------------------------------------------ | ----------------------------------------------------------------- | ------------------------------------------------- |
| `CatalogStore`, `FavoritesStore`, `SessionStore` | signal, computed                                                  | состояние, производные значения                   |
| Фильтры каталога из адреса                       | input()                                                           | роутер сам кладёт параметры во входы              |
| Часы                                             | `timer` → `toSignal`                                              | источник — время, шаблону нужно значение          |
| Статус сети                                      | `merge` + `fromEvent` → `toSignal`                                | несколько источников событий                      |
| Поиск                                            | signal → `toObservable` → debounce, switchMap, retry → `toSignal` | пауза, отмена и повторы — сильные стороны RxJS    |
| Уведомления                                      | `Subject`                                                         | событие без текущего значения                     |
| Тост                                             | `switchMap` + `timer`                                             | отмена таймера при новом событии                  |
| Заявка на бронь                                  | `exhaustMap`                                                      | игнорировать повторные клики                      |
| Кэш студий                                       | `shareReplay`                                                     | один запрос на всех подписчиков                   |
| Студии владельца                                 | `rxResource`                                                      | данные экрана: загрузка, значение, ошибка, повтор |
| Страница студии                                  | resolver                                                          | данные нужны до показа страницы                   |

## Как проверять новый код

1. Есть ли у этого «текущее значение»? Да — сигнал.
2. Важно ли время: пауза, порядок, отмена? Да — RxJS.
3. Это загрузка данных для экрана? `resource`.
4. Нужно и то и другое — поток внутри, сигнал снаружи.

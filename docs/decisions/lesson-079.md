# Урок 79. Границы доверия в StudioSlot

Описание студии вводит владелец. Для показа пользовательского текста используйте интерполяцию
Angular, а для редактирования — значение поля. HTML-разметка в описании должна оставаться текстом.
Обход санитизации через bypassSecurityTrustHtml здесь не нужен.

Production-сборка формирует CSP с хешами скриптов через security.autoCsp. Соберите приложение
командой `npm run build:prod` и найдите Content-Security-Policy в итоговом index.html. В режиме
разработки политика отличается.

Для относительных изменяющих запросов HttpClient использует пару XSRF-TOKEN и X-XSRF-TOKEN. В
приложении с cookie-аутентификацией сервер должен выдать cookie и проверить заголовок до изменения
данных. MSW этого курса имитирует refresh-сессию в пределах вкладки. Настройка клиента сама по себе
серверную проверку не реализует.
